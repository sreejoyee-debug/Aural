## Codebase Patterns
- MyApp is in `ralph/myapp/` — a React + TypeScript + Vite project
- Database layer is in `src/db/` with schema, migrations, and a localStorage-backed store
- Migrations follow the `NNN_description.ts` naming convention in `src/db/migrations/`
- Each migration exports a default object with `up()` and `down()` methods returning SQL strings
- Schema types are defined in `src/db/schema.ts` — this is the canonical source of truth
- Use `isValidPriority()` type guard when accepting priority values from user input
- Run `npx tsc --noEmit` for typecheck, `npm run lint` for lint (oxlint)
- UI components use inline styles for styling (no CSS imports for component-specific styles)
- Task cards render with colored priority badges at the left using background colors and borders
- Priority colors: high=#fee2e2 bg, #dc2626 text; medium=#fef3c7 bg, #d97706 text; low=#f3f4f6 bg, #6b7280 text
