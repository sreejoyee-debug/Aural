# 🎧 Aural — Hear Beyond

> **Music isn't just something you hear. It's something you feel.**

**Aural** is an immersive, AI-powered music discovery and listening experience designed to go beyond traditional music streaming. Instead of simply searching for songs, Aural helps users **discover music through moods, colors, places, conversations, and emotions**.

The goal is to transform music discovery from a simple search experience into an **interactive journey of exploration and self-expression.**

---

## ✨ What Makes Aural Different?

Traditional music platforms usually focus on **what you already know**.

Aural focuses on:

> **What you might love next.**

From discovering music based on your current mood to exploring songs from different parts of the world, Aural combines **AI, personalization, interactive visuals, and modern web technologies** to create a more engaging listening experience.

# 💻 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/sreejoyee-debug/Aural.git
```

## 2. Navigate into the project

```bash
cd Aural
```

## 3. Install dependencies

```bash
npm install
```

## 4. Configure environment variables

Create a `.env.local` file and add the required API credentials.

Example:

```env
NEXT_PUBLIC_API_URL=

SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=

AI_API_KEY=

DATABASE_URL=
```

> **Never commit API keys, passwords, or other secrets to GitHub.**

## 5. Start the development server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
